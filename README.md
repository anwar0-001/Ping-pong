# Ping-pong

A lightweight, single-player ping-pong game. Control the left paddle while a computer opponent plays on the right.

## Play online

https://anwar0-001.github.io/Ping-pong/

## Controls

- Move the mouse over the game or drag on the game table to move your paddle.
- Use the up and down arrow keys or W and S.
- Press Space to pause or resume.
- First player to 7 points wins. Choose Easy, Classic, or Fast before starting.

## Run locally

Open `index.html` in a modern browser. The game uses plain HTML, CSS, and JavaScript; it needs no build step or dependencies.

Your best score is saved in local browser storage. No account or server is required.
